# Look Out!
A game about an ant trying to collect food and survive. Collect falling fruit scraps while sliding and stomping feet try to squish you. Made for the Oct 2026 Jame Gam. Play here: [https://beeey.itch.io/look-out](https://beeey.itch.io/look-out)
